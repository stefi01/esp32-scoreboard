Kickoff. One repo for both screens.

Repo: https://github.com/stefi01/esp32-scoreboard
Branch main. Folder ota.

Upload these files into ota:
  version.txt
  kick_7.bin
  kick_43.bin

version.txt is the same number for both boards.
The 7 inch sketch installs kick_7.bin.
The 4.3 sketch installs kick_43.bin.
KICK_VER in each sketch is 1.0.
CHECK only offers a higher number than the one already on the desk.

After you compile kickoff7.ino, copy kickoff7.ino.bin to ota/kick_7.bin.
After you compile kickoff43.ino, copy kickoff43.ino.bin to ota/kick_43.bin.
Raise KICK_VER in both sketches, and version.txt, when the clubs change.
Upload both bin files whenever version.txt goes up.
